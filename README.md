# AYNIS Wedding Manager V3.0 FULL — Finance Flow

Versi implementasi penuh konsep utama:
- 1 tampilan aplikasi: Home / Wedding / Keuangan / Kalender / Vendor
- Form Tambah Wedding berurutan: Data Pengantin → Paket → Isi Paket/Vendor
- Vendor bisa dipilih dari database, harga referensi boleh diubah per wedding
- Pembayaran klien bertahap
- Pengeluaran/vendor dan pembayaran vendor
- Harga Deal, Uang Masuk, Sisa Tagihan, Total Pengeluaran, Estimasi Untung, Uang Pegangan
- Kalender otomatis
- Penyimpanan lokal browser + migrasi data versi lama

Data tetap tersimpan di browser/perangkat yang sama (localStorage).
